# Employee Attrition Analysis

## Project Overview

This project analyzes employee attrition to identify patterns and factors that may influence employees leaving an organization.

## Tools Used

- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Tableau

## Project Files

- 'Assignment.ipynb' — Python data analysis and visualization

## Tableau Dashboard

[View Interactive Tableau Dashboard](https://public.tableau.com/views/Atetete/Dashboard1?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)

## Key Insights

The analysis explores employee attrition across factors such as department, age, job role, job satisfaction, work-life balance, and other employee characteristics.

## Business Recommendations

The findings can help organizations identify areas of concern and develop strategies to improve employee retention and reduce attrition.
